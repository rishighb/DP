# DEVI PRASAD — Video Editing & Motion Design Portfolio

A high-performance, dark-cinematic portfolio website built to replicate the Behance case study with custom charcoal brush canvas aesthetic, artwork production marks, dual color palettes, interactive media players, and full responsiveness.

---

## 🎨 Visual Aesthetics & Design System
- **Charcoal-Washed Fine Art Canvas Background**: High-resolution vertical brushed charcoal paper (`assets/charcoal_paper_dark.jpg`), adapted directly from the user's reference image with whites and greys toned down into deep graphite and ash charcoal tones (subtle muted highlights, deep obsidian base) for optimal contrast and readability.
- **Signs of Artwork Done**:
  - Pencil drafting guidelines and technical alignment crosshairs `+`.
  - Soft charcoal rubs and graphite smudges.
  - Realistic translucent masking tape strips pinned across artwork plates.
  - Fine acrylic spray paint mist and ink spatter.
  - Technical print crop brackets (`⌜ ⌝ ⌞ ⌟`).
  - Rubber stamp proof mark (`★ PROOF APPROVED // 4K 60FPS`).
- **Hero Display**: Distressed stencil `PORTFOLIO` typography with red spray gradient and ambient glow, layered with Devi Prasad's cutout portrait.
- **Color Palettes**:
  - **Crimson Palette (Default)**: `#AD2831`, `#800E13`, `#640D14`, `#38040E`, `#250902` (exact hex codes from uploaded swatch, powering gradients, progress bars, glowing titles, and pill buttons).
  - **Luna Palette (Alternative)**: `#A7EBF2`, `#54ACBF`, `#26658C`, `#023859`, `#011C40` (instant one-click toggle in navigation bar with memory persistence).
- **Typography**: Google Fonts `Syne`, `Bebas Neue`, `Plus Jakarta Sans`, and `Space Mono`.

## 💻 How to Open & Run

You can view the portfolio immediately in any web browser:
1. Double-click [index.html](file:///c:/DP/index.html) in your file manager, OR
2. Run a simple static HTTP server:
   ```powershell
   python -m http.server 8080 -d C:\DP
   ```
   and navigate to `http://localhost:8080` in your browser.
